# Oblikovanje pozivov in varno delo z orodji UI

## ID modula

M18-pozivi-ui

## Naziv modula

Oblikovanje pozivov in varno delo z orodji UI

## Opis

Modul obravnava naprednejše oblikovanje pozivov in učinkovito uporabo generativne umetne inteligence pri konkretnih delovnih nalogah. Udeleženci spoznajo strukturirane in večstopenjske pozive, delo z dokumenti ter vključevanje orodij umetne inteligence v poslovne postopke. Posebna pozornost je namenjena varovanju podatkov, preverjanju zanesljivosti rezultatov, etičnim vidikom in odgovornosti človeka pri uporabi umetne inteligence.

## Ključne besede

Oblikovanje pozivov, pozivno inženirstvo, generativna UI, poslovna uporaba UI, kritično vrednotenje rezultatov, varna uporaba UI, etika UI.
