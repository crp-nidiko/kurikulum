# Osnove in praktična uporaba umetne inteligence

## ID modula

M17-uvod-ui

## Naziv modula

Osnove in praktična uporaba umetne inteligence

## Opis

Modul predstavlja osnove umetne inteligence, generativnih modelov in njihove praktične uporabe. Udeleženci spoznajo temeljne koncepte, zmožnosti in omejitve orodij umetne inteligence ter uporabo digitalnih asistentov pri vsakodnevnih in delovnih opravilih. Poudarek je na izbiri primernih nalog, oblikovanju osnovnih pozivov in kritičnem vrednotenju rezultatov umetne inteligence.

## Ključne besede

Umetna inteligenca, generativna UI, jezikovni modeli, digitalni asistenti, uporaba UI, produktivnost z UI.
